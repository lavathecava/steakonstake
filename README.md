# Steak on Stake

Modern marketing site for a premium steakhouse — inspired by quick-service brand layouts, with a clean white background and bold hero sections.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx --yes serve .
```

Then visit `http://localhost:3000`.

## Structure

- `index.html` — single-page layout (hero, menu, promos, locations, rewards)
- `css/styles.css` — responsive styles
- `js/main.js` — mobile navigation and demo rewards form
